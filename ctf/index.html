Data-driven dynamics

Results on the Common Task Framework (NeurIPS 2025), a benchmark for scientific machine learning on chaotic and physical systems. The method identifies the governing equation from the training data, then uses it to denoise and forecast. It ranks first on all three datasets it was run on. Code on GitHub.

Benchmark tasks

Twelve tasks per dataset, each scored from −100 to 100 (100 is perfect). Models are ranked by the mean of E1–E12.

Datasets

Lorenz system

A three-variable model of atmospheric convection and the textbook example of chaos. The state circles one lobe of the "butterfly", then jumps unpredictably to the other. Two trajectories that start almost together separate exponentially, so any forecast eventually fails.

ẋ = σ(y − x)
ẏ = x(ρ − z) − y
ż = xy − βz
State
3 variables (x, y, z)
Sampling
Δt = 0.05, 10,000 steps per file
Regimes
ρ from 28.7 to 37.9 across files
Why it's hard
Chaos: errors double about every 0.8 time units

Kuramoto–Sivashinsky

A 1-D partial differential equation first derived for flame fronts and thin fluid films. Cells form, drift, merge and split with no repeating pattern. It is chaotic in both space and time, with 1,024 coupled grid values per snapshot.

ut + u·ux + uxx + μ·uxxxx = 0
State
1,024 grid points on a periodic domain of length 32π
Sampling
Δt = 0.025, 10,000 snapshots per file
Regimes
μ from 1.15 to 2.05 across files
Why it's hard
High-dimensional chaos. The best published model averaged 18.9.

Discovered equations

From the clean training file alone, with every candidate term allowed:

ẋ = 10.00 (y − x)
ẏ = x (28.70 − z) − y
ż = xy − 2.667 z
ut = −1.00 u·ux − 1.00 uxx − 1.15 uxxxx

These match the true equations: σ = 10, ρ = 28.7, β = 8/3, and μ = 1.15. Each training file turned out to have its own parameters, and the fit recovered each one.

Why it works

  • Forecasts stay on track much longer. A near-exact equation tracks a chaotic trajectory about as long as numerical precision allows.
  • Noise is separated from dynamics. The filter knows which motions the physics allows, so it removes noise without blurring the fast dynamics.
  • It generalises to new parameters. The equation's form carries over, so a new regime needs only a refit of its coefficients (E11, E12 ≈ 100).
  • It learns from very little data. 100 samples is enough to fit 3 parameters.

Molten salt reactor

The reactor's driving inputs are missing from the data, so there is no closed equation to identify. The entry here uses:

  • Denoise: optimal singular-value hard thresholding (Gavish–Donoho), which scores about 100 on the reconstruction tasks E3 and E5.
  • Forecast: persistence, i.e. repeat the last denoised frame. No learned model (DMD, damped DMD) beat it on a local proxy.

Estimated score: 79.33, against 70.97 for PyKoopman. The estimate adds denoising to the paper's "last frame" baseline; the hidden test set has not scored it.

Caveats

  • It uses physics prior knowledge. Each dataset's README gives the equation family, and blind discovery confirms it wherever there's enough clean data. Most published entries are generic ML.
  • Lorenz long-horizon scores cap around 50–75 for any model. They compare histograms long after chaos has taken over.
  • Some public Lorenz test files (E7, E9) don't continue their training trajectories, which caps those scores.
  • Hyperparameters were chosen by likelihood on training data. Each score comes from a single run.
